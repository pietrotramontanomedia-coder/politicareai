Convertitore contatti per la newsletter

Funziona senza internet: il file resta sul vostro computer e non viene inviato a nessuno.

1. Scegliete il file

In Excel: File → Salva con nome → CSV (delimitato dal separatore di elenco). La prima riga deve contenere i nomi delle colonne (Email, Nome, Cognome, Telefono, Città, Data iscrizione, Evento…).

2. Risultato

Colonne riconosciute

Controllate che ogni colonna sia finita nel posto giusto. Le colonne «altro» vengono comunque conservate.

3. Scaricate i file

Il file per Listmonk si importa da Iscritti → Importa, con separatore virgola. Il file di controllo si apre in Excel: correggete le righe scartate nel file originale e riconvertitelo.
